### GoF Criacional
#### Contexto (Problema)

No aplicativo do Detran-DF, o usuário informa a placa e o Renavam do veículo para consultar débitos, restrições, financiamentos ou emitir o "nada consta". Ao analisar o fluxo do aplicativo, percebe-se que todas as quatro opções partem da mesma tela inicial e entregam um retorno direto ao usuário. No entanto, embora a interface precise lidar com essas consultas de forma uniforme, cada uma delas é implementada de maneira diferente no sistema. Sem um padrão estrutural o cliente escolheria qual consulta instanciar utilizando uma estrutura condicional:

```python
if tipo == "debitos":
    consulta = ConsultaDebitos()
elif tipo == "restricoes":
    consulta = ConsultaRestricoes()
elif tipo == "financiamentos":
    consulta = ConsultaFinanciamentos()
```

Contudo essa abordagem é incorreta, visto que causa:
   * Acoplamento: o cliente conhece todas as classes concretas.
   * Violação do Open/Closed: cada novo tipo (por exemplo, “consulta de multas”) obriga a editar o cliente.
   * Duplicação: o mesmo if/elif tende a se repetir em cada tela ou fluxo que faz consultas.

Aqui entra o Factory Method:
  O padrão move a decisão de qual consulta criar para subclasses de um Creator. O cliente passa a depender apenas da abstração Consulta, e incluir um novo tipo significa adicionar duas classes (o produto e o seu creator), sem alterar o código existente.

### Implementação do diagrama em código

```python
@dataclass
class ResultadoConsulta:
    tipo: str
    itens: list[str] = field(default_factory=list)

    @property
    def limpo(self) -> bool:
        return not self.itens

    def __str__(self) -> str:
        if self.limpo:
            return f"[{self.tipo}] nada consta"
        return f"[{self.tipo}] " + "; ".join(self.itens)


# Product
class Consulta(ABC):
    def __init__(self, base: BaseDetran) -> None:
        self._base = base

    @abstractmethod
    def executar(self, renavam: str) -> ResultadoConsulta: ...


# Concrete Products
class ConsultaDebitos(Consulta):
    def executar(self, renavam: str) -> ResultadoConsulta:
        return ResultadoConsulta("Débitos", self._base.debitos.get(renavam, []))


class ConsultaRestricoes(Consulta):
    def executar(self, renavam: str) -> ResultadoConsulta:
        return ResultadoConsulta("Restrições", self._base.restricoes.get(renavam, []))


class ConsultaFinanciamentos(Consulta):
    def executar(self, renavam: str) -> ResultadoConsulta:
        return ResultadoConsulta("Financiamentos", self._base.financiamentos.get(renavam, []))


class ConsultaNadaConsta(Consulta):
    def executar(self, renavam: str) -> ResultadoConsulta:
        itens = (
            self._base.debitos.get(renavam, [])
            + self._base.restricoes.get(renavam, [])
            + self._base.financiamentos.get(renavam, [])
        )
        return ResultadoConsulta("Nada Consta", itens)

```
