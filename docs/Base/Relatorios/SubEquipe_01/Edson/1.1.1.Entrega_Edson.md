### GoF Criacional
#### Contexto (Problema)

No aplicativo do Detran-DF, o usuário informa a placa e o Renavam do veículo para consultar débitos, restrições, financiamentos ou emitir o "nada consta". Ao analisar o fluxo do aplicativo, percebe-se que todas as quatro opções partem da mesma tela inicial e entregam um retorno direto ao usuário. No entanto, embora a interface precise lidar com essas consultas de forma uniforme, cada uma delas é implementada de maneira diferente no sistema. Sem um padrão o cliente escolheria qual consulta instanciar utilizando uma estrutura condicional:

```python
if tipo == "debitos":
    consulta = ConsultaDebitos()
elif tipo == "restricoes":
    consulta = ConsultaRestricoes()
elif tipo == "financiamentos":
    consulta = ConsultaFinanciamentos()
```

Contudo essa abordagem é incorreta, visto que causa:
   * Acoplamento: o cliente conhece todas as classes concretas.
   * Violação do Open/Closed: cada novo tipo (por exemplo, “consulta de multas”) obriga a editar o cliente.
   * Duplicação: o mesmo if/elif tende a se repetir em cada tela ou fluxo que faz consultas.

Aqui entra o Factory Method:
  O padrão move a decisão de qual consulta criar para subclasses de um Creator. O cliente passa a depender apenas da abstração Consulta, e incluir um novo tipo significa adicionar duas classes (o produto e o seu creator), sem alterar o código existente.

### Implementação do diagrama em código

```python

class BaseDetran:
    """Simulação das fontes de dados que o app consulta (inferido, não observado)."""

    def __init__(self) -> None:
        self.debitos = {"98765432100": ["IPVA 2026: R$ 1.250,00", "Multa: R$ 195,23"]}
        self.restricoes = {"98765432100": ["Restrição judicial (RENAJUD)"]}
        self.financiamentos = {"55555555555": ["Alienação fiduciária - Banco X"]}

@dataclass
class ResultadoConsulta:
    tipo: str
    itens: list[str] = field(default_factory=list)

    @property
    def limpo(self) -> bool:
        return not self.itens

    def __str__(self) -> str:
        if self.limpo:
            return f"[{self.tipo}] nada consta"
        return f"[{self.tipo}] " + "; ".join(self.itens)


# Product
class Consulta(ABC):
    def __init__(self, base: BaseDetran) -> None:
        self._base = base

    @abstractmethod
    def executar(self, renavam: str) -> ResultadoConsulta: ...


# Concrete Products
class ConsultaDebitos(Consulta):
    def executar(self, renavam: str) -> ResultadoConsulta:
        return ResultadoConsulta("Débitos", self._base.debitos.get(renavam, []))


class ConsultaRestricoes(Consulta):
    def executar(self, renavam: str) -> ResultadoConsulta:
        return ResultadoConsulta("Restrições", self._base.restricoes.get(renavam, []))


class ConsultaFinanciamentos(Consulta):
    def executar(self, renavam: str) -> ResultadoConsulta:
        return ResultadoConsulta("Financiamentos", self._base.financiamentos.get(renavam, []))


class ConsultaNadaConsta(Consulta):
    def executar(self, renavam: str) -> ResultadoConsulta:
        itens = (
            self._base.debitos.get(renavam, [])
            + self._base.restricoes.get(renavam, [])
            + self._base.financiamentos.get(renavam, [])
        )
        return ResultadoConsulta("Nada Consta", itens)

# Creator
class ConsultaCreator(ABC):
    def __init__(self, base: BaseDetran) -> None:
        self._base = base

    @abstractmethod
    def criar_consulta(self) -> Consulta:
        """Factory Method: subclasses decidem qual Consulta instanciar."""

    def consultar(self, crv: CRV) -> ResultadoConsulta:
        consulta = self.criar_consulta()
        return consulta.executar(crv.veiculo.renavam)


# Concrete Creators
class DebitosCreator(ConsultaCreator):
    def criar_consulta(self) -> Consulta:
        return ConsultaDebitos(self._base)


class RestricoesCreator(ConsultaCreator):
    def criar_consulta(self) -> Consulta:
        return ConsultaRestricoes(self._base)


class FinanciamentosCreator(ConsultaCreator):
    def criar_consulta(self) -> Consulta:
        return ConsultaFinanciamentos(self._base)


class NadaConstaCreator(ConsultaCreator):
    def criar_consulta(self) -> Consulta:
        return ConsultaNadaConsta(self._base)


# Testando

if __name__ == "__main__":
    base = BaseDetran()

    print("\n== FACTORY METHOD ==")
    for creator in (DebitosCreator(base), RestricoesCreator(base),
                    FinanciamentosCreator(base), NadaConstaCreator(base)):
        print(creator.consultar(crv_pendente))

```
