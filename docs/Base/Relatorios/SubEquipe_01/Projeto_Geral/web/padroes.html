Fluxo integrado da emissão do CRLV-e

  1. EmissaoCRLVeCreator(uf) obtém a base da UF pelo Multiton.
  2. O Factory Method do Ricardo cria o ServicoEmissaoCRLVe.
  3. O serviço usa o Factory Method do Edson (NadaConstaCreator) para conferir pendências.
  4. Sem pendências, o Prototype do Yuri clona o CRLVe base e preenche placa, RENAVAM e exercício.
  5. Com pendências, a emissão é recusada e nenhum clone é criado.
MVP acadêmico: dados simulados, sem relação com o sistema real do DETRAN-DF. Padrões de Edson, Ricardo e Yuri.
